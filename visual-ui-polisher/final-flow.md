# Pretty UI Flow

1. Read project context
   Use PROJECT.md, CONTEXT.md, PRD.md, TASKS.md, AGENTS.md or equivalent docs.

2. Run grill-with-docs
   Check if the screen still satisfies the product/domain requirements.

3. Run visual-ui-polisher
   Identify what makes the screen visually weak, generic, unbalanced, or unfinished.

5. Run design-system-aligner
   Turn visual decisions into reusable tokens and component patterns.

6. Run frontend-implementation-planner
   Convert the improvements into small, safe implementation tasks.

7. Run visual-qa
   After implementation, compare the result against the intended direction.
