# Article patterns — legacy compatibility

This path is retained for existing callers, but its earlier section-by-section templates caused repetitive articles. Choose an evidence-dependent mode from [narrative-modes.md](narrative-modes.md) instead.

| Previous pattern | Suggested narrative mode | What matters |
|---|---|---|
| Project retrospective | Build journal / experiment | Real evolution, outcomes and constraints |
| Prototype became a real tool | Build journal + architecture decision | Why the prototype no longer fit actual needs |
| AI-assisted development | Experiment or technical analysis | Observable agent behavior, validation and guardrails |
| Technical opinion | Myth testing | Fair counterargument, specific evidence, bounded claim |

For migrations, incidents, tutorials, performance investigations, research reviews and comparisons, use the corresponding mode in `narrative-modes.md`.

These are prompts for *questions*, not headings. Never add an undocumented failure, naive first attempt, benchmark or lesson solely to fill a section.
